# Benoît Roussel

PhD student in computer vision at Idemia and École Centrale de Lyon (LIRIS).
I work on **end-to-end multi-object tracking**: detection and association
learned jointly in a single model, and identities kept through long occlusions.

[Website](https://benoitroussel.com) · [Google Scholar](https://scholar.google.com/citations?user=d9izL3IAAAAJ&hl=en) · [LinkedIn](https://www.linkedin.com/in/btroussel)
